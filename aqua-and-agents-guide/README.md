# Aqua & Agents Guide

Aqua, Code Ocean’s built-in AI agent, is powered by state-of-the-art models and a curated knowledge base to enable any user, not just expert coders, to create, edit, and run computational analyses.

Aqua works with the Code Ocean Model Context Protocol (MCP), and is able to not only explain platform concepts, but also find and create assets, edit files, run Capsules and Pipelines, and return reproducible results with full lineage and traceability.

In addition, the public MCP server allows external agents like Claude to safely act within Code Ocean using your unique permissions—without sacrificing control or compliance.
