# Code Ocean Apps

Code Ocean Apps is a dashboard of ready-to-use applications. These Apps can be used with or without customization as a Capsule and in Pipelines.

Capsules are categorized as:

1. [Genomics](genomics.md)&#x20;
   * [Bulk Sequencing](genomics.md#bulk-sequencing)
   * [Single Cell](genomics.md#single-cell)
   * [Utilities](genomics.md#utilities)
   * [Other](genomics.md#other)
2. [Cheminformatics](cheminformatics.md)
3. [Visualization](visualization.md)
4. [Machine Learning](machine-learning.md)
5. [Data Connectors](data-connectors.md)
6. [Quality Control](quality-control.md)

{% hint style="info" %}
Note there are multiple RNA and DNA aligners available in the Apps Library. Which to use depends on personal preference or the specific purpose. For example, Salmon is tailored to transcript quantification, STAR might be more suitable for structural variant detection or other types of analyses of RNA-Seq data. For guidance, feel free to post on the Code Ocean community slack or contact [support@codeocean.com](mailto:support@codeocean.com).&#x20;
{% endhint %}
