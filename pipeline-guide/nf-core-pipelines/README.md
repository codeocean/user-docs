# nf-core Pipelines

nf-core is a community effort to collect a curated set of analysis pipelines built using Nextflow. It provides portable, documented, automated pipelines that guarantee reproducibility. These pipelines can be accessed in Code Ocean through a single button import function. This provides easy access to 100+ standardized and customizable workflows, which can greatly reduce the time to perform new analyses. &#x20;

This section covers how to [Import nf-core pipelines](import-nf-core-pipelines.md) and go through an [nf-core RNAseq tutorial](nf-core-rnaseq-tutorial/).&#x20;
