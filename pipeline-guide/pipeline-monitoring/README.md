# Pipeline Monitoring

Upon executing a run in Code Ocean, the Monitoring dashboard automatically appears in the Pipeline IDE, providing real-time insights into your Pipeline's progress. Users can access this view at any time by clicking the blue **Monitoring** button in the timeline for ongoing runs, or selecting **Monitoring** from the Run's actions menu for completed runs.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot 2025-01-30 at 10.51.54 AM.png" alt=""><figcaption><p>Monitoring for ongoing runs.</p></figcaption></figure>

<figure><img src="../../.gitbook/assets/Screenshot 2025-01-30 at 10.51.09 AM.png" alt=""><figcaption><p>Monitoring for completed runs.</p></figcaption></figure>

The Monitoring dashboard contains:

* [General Info](monitoring-dashboard.md#general-info)
* [Resource Summary](monitoring-dashboard.md#resource-summary)
* [Tasks Status](monitoring-dashboard.md#tasks-status)
* [Table of Processes](monitoring-dashboard.md#table-of-processes) and [Visual Pipeline Monitor](monitoring-dashboard.md#visual-pipeline-monitor)

Clicking on a Process in the table opens a Task side panel. This side panel contains:

* [Table of Tasks](task-details.md#table-of-tasks)
* [Task Details](task-details.md#task-details)
