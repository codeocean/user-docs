# Reproducibility Panel

At the top of the Reproducibility panel on the right side of the Pipeline IDE, users will find the "Reproducible Run" or "Run with parameters" button to launch their Pipeline run.&#x20;

For custom and nf-core Pipelines, users will see the option to launch a Cloud Workstation: VS Code or Terminal.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot 2025-09-10 at 2.15.01 PM.png" alt="" width="297"><figcaption></figcaption></figure>

{% hint style="info" %}
The Cloud Workstations are currently for Pipeline development only. Users will not be able to run their Pipelines within this environment.&#x20;
{% endhint %}

Below this section is the Timeline, which provides a history of Pipeline creation, runs, committed file changes, and releases. Events in the Timeline can be filtered to show All events, Commits, All Runs, My Runs, or Releases. The search bar can be used to search Computation Names of Reproducible Runs, Commit Messages, and Release Versions to further select what is visible in the Timeline.
