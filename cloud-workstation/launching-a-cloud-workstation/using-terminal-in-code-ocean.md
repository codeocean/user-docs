# Using Terminal in Code Ocean

You can use the **Terminal Cloud Workstation** to access a command-line interface on Code Ocean. This is good for inspecting the file system, testing out dependency installations, and trying out new ideas.

### Launching a Terminal Cloud Workstation <a href="#launching-a-terminal-cloud-workstation" id="launching-a-terminal-cloud-workstation"></a>

After [selecting your Starter Environment](../../setting-up-the-environment/starter-environment.md), select the **Terminal Cloud Workstation** icon to access the command-line interface for your Capsule.

![](<../../.gitbook/assets/Screen Shot 2024-02-05 at 3.47.31 PM (1).png>)

The Terminal will launch automatically, providing immediate access to your Capsule's environment.&#x20;

![](<../../.gitbook/assets/Code Ocean 2022-06-06 at 5.16.57 PM.png>)
