# Using Ubuntu Desktop in Code Ocean

The Ubuntu Desktop Cloud Workstation provides a desktop-like environment in Code Ocean ideal for using Ubuntu desktop-compatible apps, running servers (e.g. Flask Apps), or having simultaneous access to programming tools and the web via Firefox.

## Preparing to launch a Ubuntu Desktop Cloud Workstation <a href="#launching-a-terminal-cloud-workstation" id="launching-a-terminal-cloud-workstation"></a>

To launch an **Ubuntu Desktop Cloud Workstation**, your Capsule must use a Starter Environment with Ubuntu Desktop pre-installed such as the one shown below. Refer to the [Selecting A Starter Environment](../../setting-up-the-environment/starter-environment.md) section for more guidance on the appropriate Starter Environment.

<figure><img src="../../.gitbook/assets/Screenshot 2024-02-16 at 10.32.16 PM.png" alt=""><figcaption></figcaption></figure>

If an unsupported Starter Environment is selected and you attempt to open the **Ubuntu Desktop Cloud Workstation**, an error message will appear, as shown in the image below.

<figure><img src="../../.gitbook/assets/Screenshot 2024-02-16 at 10.30.27 PM.png" alt="" width="563"><figcaption></figcaption></figure>

## Launching an Ubuntu Desktop Cloud Workstation

After selecting your Starter Environment, select the **Ubuntu Desktop Cloud Workstation** icon to access a desktop view of your Capsule.

<figure><img src="../../.gitbook/assets/Screenshot 2024-02-16 at 10.28.37 PM.png" alt="" width="375"><figcaption></figcaption></figure>

Once launched, you will see the Ubuntu Desktop interface, providing full access to the desktop environment.

<figure><img src="../../.gitbook/assets/Screenshot 2024-02-16 at 10.36.26 PM.png" alt=""><figcaption></figcaption></figure>
