# MLflow UI

## Manage Experiments

Once you have completed your first tracked run, you can now view and manage your experiment, runs, and models in MLflow.&#x20;

Access the MLflow UI from a Capsule or Pipeline by clicking “View in MLflow” in the header, to enter into the associated experiment in the MLflow UI.&#x20;

## View Runs in MLflow

For each tracked computation, click “View Run in MLflow” in the run actions menu found in the Capsule or Pipeline Timeline to enter into the associated run in the MLflow UI.
