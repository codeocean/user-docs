# Creating Models

## **View and Register Models in MLflow**

Click “View Model in MLflow” in the actions menu of models found in the Capsule or Pipeline Timeline to open that model in the MLflow UI.&#x20;

From here, you can register models for model lifecycle management and version control. Registering a model in MLflow will also create a Registered Model in your Code Ocean Models dashboard that includes provenance and lineage.

See [Registering Models in MLflow](../models-guide/creating-models.md#registering-models-in-mlflow) for more information. &#x20;

## **Create Models with Provenance**

In addition to registering models in the MLflow UI, you can also capture any computation model (indicated in the Capsule or Pipeline Timeline by a “Model” icon) as a Code Ocean Model that includes automatically-generated provenance and lineage. These Models can be shared and attached to a Capsule or Pipeline for downstream analysis.&#x20;

See [Creating Models from the Timeline](../models-guide/creating-models.md#creating-models-from-the-timeline) for more information. <br>
