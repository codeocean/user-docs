# MLflow Guide

## About MLflow

[MLflow](https://mlflow.org/) is an open-source platform for managing the end-to-end machine learning lifecycle. With MLflow enabled, you can create MLflow experiments that will track runs from Capsules and Pipelines, monitor and manage your experiments within the integrated MLflow tracking server, and register models for downstream workflows. This version of Code Ocean currently runs MLflow v3.6.0.
