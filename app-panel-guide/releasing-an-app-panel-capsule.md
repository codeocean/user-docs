# Releasing an App Panel Capsule

## Release Functionality

There are two release functionality modes for a Capsule with an App Panel. This can be seen and set under the **Release Functionality** section. This determines the view and accessibility for when the Release Capsule is accessed. **Preview** enables a view of each option.

<figure><img src="../.gitbook/assets/Screen Shot 2024-01-30 at 2.22.03 PM.png" alt="" width="375"><figcaption></figcaption></figure>

*   Standard Capsule release:&#x20;

    This allows other users to switch to the File Tree tab and access the original scripts and other files.
*   No-Code App release:&#x20;

    Users will only see the App Panel in this mode, and none of the files that compose the Capsule. The  no-code app option is also available for Capsules running Shiny, Streamlit, Ubuntu, and IGV [Cloud Workstations](../cloud-workstation/).&#x20;

{% hint style="info" %}
All owners of the Capsule will be able to set the release functionality.
{% endhint %}

You can click on the **Preview** to see what it looks like publishing in No-Code App:

<figure><img src="../.gitbook/assets/Screen Shot 2024-01-30 at 2.32.43 PM.png" alt=""><figcaption></figcaption></figure>

Capsules released as **No-Code App**, cannot be duplicated and will appear with an **Open No-Code App** link on the Internal Releases pag&#x65;**.** &#x20;
