# Activity Center

The **Activity Center**, accessible from the main navigation bar, provides a centralized view of user-triggered long-running operations, whether initiated via UI or API—such as Data Asset creation, imports, and downloads.&#x20;

<figure><img src=".gitbook/assets/Screenshot 2025-07-17 at 3.35.24 PM.png" alt="" width="563"><figcaption><p>Activity Center</p></figcaption></figure>

Jobs that will appear in the Activity Center include:

* All Data Asset creation events (with the exception of local files)
* Importing a Code Ocean Apps Capsule
* Data Asset Transfer (via Public API)
* All download events (e.g. logs, support bundle, files)

{% hint style="info" %}
For downloads, once file preparation is complete, if you remain on the same page, the download will begin automatically. If you navigate away before preparation finishes, you'll need to manually click **Download** from the **Activity Center** once the files are ready.&#x20;

This Download link remains available for **6 hours**. After that, you'll need to initiate the download again.&#x20;
{% endhint %}

Each job will have one of the following statuses:

* In Progress&#x20;
* Completed
* Cancelled
* Failed

{% hint style="info" %}
Relevant jobs can be cancelled directly from the Activity Center.
{% endhint %}
