# Results

## Results

The content of only the most recently generated results appears in the `/results` folder, while all generated results will appear in the **Timeline** in the panel on the right.

<figure><img src="../../.gitbook/assets/image (525).png" alt=""><figcaption></figcaption></figure>

Files cannot be uploaded to the `/results` folder, and can only be generated in the `/results` folder during a run. At the beginning of each computation, either a Reproducible Run or Cloud Workstation session, `/results` is empty and you cannot reuse the results from a previous run.

If you want to reuse results generated from a computation, see the [Capturing a Result Guide](../../data-assets-guide/capturing-a-result/). You can download, delete, and rename each run folder by clicking on the drop-down menu.
