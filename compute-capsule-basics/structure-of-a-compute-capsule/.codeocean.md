# .codeocean

Capsules created in Code Ocean v2.22 and later include a `/.codeocean` folder, which materializes all Capsule files in a Git repository. These files are read only, and will be automatically edited when needed. The user will never need to edit these files directly.

## app-panel.json

* Records details of each parameter in the App Panel and tracks any changes made.
* Enables updates to the App Panel to be committed to Git.

## datasets.json

* Tracks which Data Assets are attached to the Capsule.
* Allows the attached Data Assets to be committed to Git for version control.

## environment.json

* Specifies the Starter Environment used by the Capsule.
* Ensures the Starter Environment configuration can be committed to Git.

## resources.json

* Records the EC2 compute instance used by the Capsule, including machine type and size.
* Enables the compute resource details to be committed to Git.

## secrets.json

* Records the metadata description of the Secrets attached to the Capsule. Each Secret remains private to the individual user and is not stored or tracked.
* Allows the Secrets metadata to be committed to Git, but not the Secrets themselves.  &#x20;
