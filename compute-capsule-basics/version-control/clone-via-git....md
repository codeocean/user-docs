# Clone via Git...

## Git clone your Capsule to your computer

1.  Click the Capsule menu and select **Clone via Git**.<br>

    <figure><img src="../../.gitbook/assets/image (386).png" alt=""><figcaption></figcaption></figure>
2. This will provide you with the appropriate Git repository URL.&#x20;

<figure><img src="../../.gitbook/assets/Screenshot 2024-02-19 at 7.18.52 PM.png" alt="" width="563"><figcaption></figcaption></figure>

1. Copy and paste the URL and via a terminal or Git client, run `git clone [url]` .
2. This will prompt you for your username and password. The username is your email used to log in to Code Ocean, and the password is the text generated by clicking "Generate New Access Token" button in the above screenshot
3. From that point, you can push, pull, etc. to the corresponding Code Ocean Capsule.

## Adding a Code Ocean Capsule as a remote to an existing git repository

This section assumes that you have a git repo on your computer and that you are reasonably comfortable with Git commands. If you are just getting started with git, you can follow along by forking and then cloning a public GitHub repo.

&#x20;1\. Click the Capsule menu and select **Clone via Git**:

<figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>

2. A message to appear with your Capsule's git information:

<figure><img src="../../.gitbook/assets/Screenshot 2024-02-19 at 7.18.52 PM.png" alt="" width="563"><figcaption></figcaption></figure>

2. Click the clipboard icon in Step 2 to copy the Github clone URL
3. Navigate to your local git repo on your computer, run `git init` if you have not already, and add the copied link as a remote (in the below example, the remote is called `co`):\
   `git remote add co https://git.codeocean.com/capsule-<id>.git`&#x20;
4. You can check this worked by running `git remove -v`&#x20;
5. Push your local files to Code Ocean by a command like `git push co master` (in this example, the repo is on the master branch but yours might not be).&#x20;
6. If this is your first time running `git push`  from your computer, you will be prompted for your username and password. Use your username and password for Code Ocean.
7. Your Capsule will then show that changes are being pushed:

<figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>

9. You can now push, pull, etc. between your local repo and Code Ocean, and the Capsule will have your full git history displayed on its Timeline.

{% hint style="info" %}
Once you've set up the capsule as a remote, you no longer need to have the capsule open, nor to be logged in, to push your code.
{% endhint %}
