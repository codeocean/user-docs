# File Navigation/App Builder Panel

## File Navigation

The Files tab on the toolbar to the left opens the **Files** panel. The **Core Files** section at the top contains the following folders: metadata, environment, code, data, as well as a .gitignore file. The next section down, **Research Data Drive,** contains the scratch folder.  Next is the **Results** section which contains the computational results of the Capsule. The last section is **Other Files** which contains any additional files.

### File Tree System Contents&#x20;

| Folder                             | Purpose                                                                                  | Contents                                                                      |
| ---------------------------------- | ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Metadata                           | Capsule's metadata                                                                       | metadata.yml                                                                  |
| Environment                        | Capsule's environment files                                                              | Dockerfile, postInstall script, environment.yml                               |
| Code                               | Code and related files                                                                   | Source files                                                                  |
| Data                               | Input data required by Reproducible Runs. May optionally contain small intermediate data | Small data files and attached datasets                                        |
| Results                            | Output files generated by the most recent Reproducible Run                               | Result files                                                                  |
| Scratch (Cloud Workstation)        | Large Intermediate data that are **NOT** required by Reproducible Runs                   | Large data files                                                              |
| Scratch (Reproducible Run)         | Large Intermediate data that are generated during Reproducible Runs                      | Large data files                                                              |
| Cloud Workstation Root File System | Package installations, IDE preferences, temporary files, etc.                            | The whole file system except the Capsule workspace, and those mounted folders |

### Managing Capsule Size&#x20;

The **Capsule Usage Information Box** can be accessed at the bottom of the File Navigation Panel and used to view your current Capsule space usage. It displays:

* Total usage - broken down by:
  * Attached Data
  * Scratch
  * Results&#x20;
  * Workspace
    * Code
    * Data
    * Environment
    * Metadata
    * Other files

To reduce storage costs in your Capsule,  is understanding the storage location of your files and how long they will remain there. The breakdown is as follows:

S3, EBS and EFS refer to the types of Amazon Cloud Storage that are possible:

* [Simple Storage Service (S3)](https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html)
* [Elastic Block Store (EBS)](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/AmazonEBS.html)
* [Elastic File System (EFS)](https://docs.aws.amazon.com/efs/latest/ug/how-it-works.html)
